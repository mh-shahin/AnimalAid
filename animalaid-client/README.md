# AnimalAid Client

## Description
AnimalAid Client is a React-based web application for managing animal feed and related products. This frontend application provides an intuitive interface for administrators to manage feed inventory, including features for adding, editing, and deleting feed products.

## Features
- Feed Management System
- Admin Dashboard
- Product Categories
- Search Functionality
- Image Upload Support
- Real-time Updates

## Tech Stack
- React.js
- Vite
- React Router DOM
- Lucide React (for icons)
- SweetAlert2 (for modals)
- React-Toastify (for notifications)

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn
